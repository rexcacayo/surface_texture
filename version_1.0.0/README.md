# Surface Texture

Complemento de Blender (4.2 a 5.x) para poner **relieve real e imprimible en cualquier pieza**:
moleteado, fibra de carbono, hexágonos, cuero, martillado, madera, piedra, ladrillo, estrías o tu
propia imagen. Todo en modo Objeto y la pieza original no se toca.

- Grabada (no cambia las medidas) o en relieve.
- Proyección para cualquier forma sin costuras, o envolvente para piezas redondas.
- La base de apoyo queda plana.

Instalar: Editar → Preferencias → Complementos → Instalar desde disco → `surface_texture-1.0.0.zip`.
Guía completa en `surface_texture/LEEME.md`.
